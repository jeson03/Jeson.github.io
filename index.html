🧬 基本操作

  1. 输入序列：在左侧输入框粘贴 DNA 序列（仅 ATCG），或使用坐标/基因名自动提取。
  2. 上传基因组：点击“📂 上传 .fa”，选择参考基因组文件（.fa）和索引文件（.fai）。
  3. 六框翻译：输入 DNA 后自动生成六个阅读框的氨基酸序列，M 为起始，* 为终止。
  4. IGV 比对：在右侧粘贴 IGV 中读出的氨基酸序列，点击“开始比对”，工具自动寻找最佳匹配区域并高亮差异。

🔍 高级功能

  • 坐标提取：输入 “chr17:7668421-7687490” 格式，自动从上传的基因组中提取对应片段。
  • 基因搜索：输入基因名（如 TP53），通过 Ensembl API 自动获取编码序列。
  • 示例库：内置多个经典基因序列，一键加载用于练习和验证。
  • 比对逻辑：支持截取片段比对，自动在六个阅读框中寻找最佳匹配区域。

💡 小技巧

  • 在输入框中修改序列后，六框翻译和统计数字会实时更新。
  • 比对结果中的红色高亮表示该位置氨基酸不匹配。
  • 使用 Ctrl+滚轮 可缩放页面，便于阅读长序列。
